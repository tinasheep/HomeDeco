## 初步觀察

- **地點**：大坪林站一帶，標榜雙捷運（新店線＋環狀線），到寶高園區很近，生活機能比羅馬山莊強。
- **頂樓**：14 樓是最高樓層，要特別注意屋頂漏水、夏天頂樓熱，以及頂樓防水由誰負責維修。
- **室內很小**：主建物只有 12.51 坪，要隔 2 房 1 廳，每間都會很小。實際能用的空間比羅馬山莊（主建物＋陽台約 18.89 坪）少很多。
- **公設與附屬建物約 34%**：18.96 坪裡有 6.45 坪不是主建物，可能包括陽台和公設，要看謄本。
- **照片**：看起來是舊磁磚地、窗型冷氣、原始狀態，大概要整修。
- **價格**：開價明顯偏高，貸款只會依銀行鑑價核貸。
